# Frame board: BOM, library and datasheet review (28 Nov 2026)

Start of the frame stage. What the frame (power board) shares with the shared libraries and the other projects, the
state of each part's symbol, footprint and datasheet, and the open decisions before its netlist and placement.
BOM source: `tools/design.py` (`FRAME_BOM`) and `tools/parts.py` (`FRAME_MPN`, `FRAME_PLACED`); order sheet
`fabrication/BOM_DigiKey.csv`; datasheet index `Materials/bom_datasheets/README.md`.

## Decisions (user, 28 Nov 2026)

| # | Topic | Decision |
|---|---|---|
| 1 | Boost input | **BAT** (approved). SYS keeps C3 / C4 (2 x 10 uF) + the TPS22810 input C8 (1 uF) = 21 uF, just over the 20 uF guideline - **accepted as is** (user 28 Nov) |
| 2 | UVLO | **Internal 2.54 / 2.41 V** lockout, so the drone has time to land; R8-R10 stay DNP |
| 3 | TS input | **keep the 103AT-2 NTC** (confirmed): charging between ~0 and 60 °C, cell temperature sensed on the 18650 |
| 4 | VSYS Schottky | **D2 MBR120VLSFT1G** added (approved) |
| 5 | Reverse polarity | **not in this design** |
| 6 | STAT readback | **not needed** |
| 7 | Slide switch | **Nidec CUS-12TB** (563-1102-1-ND): the APEM MA12R/TR is obsolete; same PCM12 land pattern, small (6.7 x 2.6 x 1.4 mm) |

## Lessons from PicoBalancer (same power chain) - the options as they were put

1. **Boost input on BAT, not SYS.** BQ25606 SLUSCK6C wants <= 20 uF on SYS; the frame has ~41 uF there today
   (TPS22810 input + boost input). PicoBalancer moved the boost (and the TPS22810) to BAT and keeps SYS for the
   charger's own caps. Recommended for the frame too (open item already).
2. **UVLO 3.30 / 2.70 V by default** (R8-R10 fitted, the internal 2.54 / 2.41 V as the 0R option). PicoBalancer made
   the divider the default for plain cells; the frame has it DNP.
3. **TS: NTC or fixed?** PicoBalancer dropped the NTC (fixed 7.55k equivalent, charging always allowed). The frame
   keeps the 103AT-2 taped to the 18650 - the better choice for a cell in a drone; keep unless you want it simpler.
4. **Back-feed Schottky to VSYS** (MBR120VLSFT1G in PicoBalancer): the Pico's own micro-USB, if plugged on the bench,
   back-feeds VSYS through the Pico's Schottky into the TPS22810 output. On the drone the Pico's USB is hidden under
   the frame and VBUS goes nowhere, so this is optional; a diode costs ~0.3 V of the cell headroom.
5. **Reverse polarity.** PicoBalancer protects each holder with a P-FET (DMP2008UFG) + N-FET gate enable (DMG2302U)
   + PPTC (1812L260). The frame has tab pads soldered once (polarity fixed at assembly) and an open item for the ESC
   leads: a single P-FET on BAT would need ~30 A peak - not practical; recommend silk polarity marks + keyed
   assembly instead, and decide the ESC lead protection separately.
6. **STAT LED from SYS + CHG_STAT readback** (PicoBalancer R36): the frame's STAT LED is from REGN with no readback;
   CHG_PG already goes to the FC. Optional.
